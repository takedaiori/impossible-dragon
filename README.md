# 🐉🍎💣 Impossible Dragon | 不可能完成的贪吃龙

试玩地址：https://takedaiori.github.io/impossible-dragon/

> 一条龙，一屏幕的诱惑与陷阱 🍓💣
>
> 你唯一要做的事，是在两者之间做出选择——
> 并且活到撑满屏幕的那一刻 ✨

---

## 🧬 它的血液里流着两个经典

**贪吃蛇** 🐍 教会它「吃到就长大」。
**Agar.io** 🔵 教会它「尺寸即一切」。

这款 Demo 把这两条基因揉进了一块屏幕：

- 你不再在网格里追着自己的尾巴跑 🏃
- 也不必在竞技场里和别人抢夺 ⚔️
- **你独自面对一整屏不断浮现又消失的 emoji** 🌊

以及一个——**几乎注定失败的目标** 🎯

---

## 🎮 玩法：一句话说得清，一辈子做不完

### 你是那条龙 🐉

在电脑上，**移动鼠标即可** 🖱️
在手机上，**按住龙拖动** 👆

没有摇杆，没有按键 🎛️❌
**龙本身就是你的光标**——这是全部的操作。

### 屏幕会不断浮出两种 emoji 🍎💣

| 遇到 | 结果 |
| :--- | :--- |
| 🍎🍇🍉 水果 | 龙长大一点 📈 |
| 💣 地雷 | 龙缩小，并消耗一次机会 ❤️➖ |

机会用尽，游戏结束 🖤

### 目标是让龙的高度撑满整个屏幕 🏔️

听起来只是「把该吃的都吃掉」😌

但屏幕上**该吃的和不该吃的长得一样多、一样随机、一样沉默** 🎭

**它们不会告诉你答案，也不会给你第二次机会。** 🤐

---

## 📐 真正难的地方，藏在几何里

游戏没有刻意设计难度曲线，却自然地长出了一条 📈

因为——**龙越大，它就占据了越多的屏幕** 🖼️
留给你的缝隙就越窄 🪡

- 🌱 开局时你是一条几乎看不见的小家伙，在空旷的纸面上从容游走
- 🐲 当你长到半屏、七成屏，每一次移动都像**在瓷器店里挪动一头巨兽** 🏺

> **你不是变弱了，是空间背叛了你。** 🌌

这是本作最诚实的地方：
它从不偷偷调高难度，是**你自己的成长把路堵死的** 🧱

---

## 🧘 它考验的不是手速，是克制

横冲直撞的人会在几十秒内耗尽机会 💥⏱️

真正的通关者，往往是那些**愿意停下来等一等的人** ⏸️

等一个没有地雷挡路的时机 🚦
等一次值得出手的呼吸 🌬️

所以这游戏名字里的「不可能」，其实是一句邀请 💌

**它想看看你有多沉得住气。** 🫖
